**Mismatch:** `host.py:3012–3015` appends `kind="reference_reconcile"` and writes bare country maps as the audit identity images. No production source or stored row was injected or manually rewritten to trigger the defect. The first attempt failed the Host's symlink-root guard for macOS `/tmp`; the corrected explicit private root resolves to `/private/tmp` and is the successful proof.

**Impact/safeguards:** Subsequent master contacts, corrections and deletions cannot cross this event through the supported stream. Existing contacts and immutable receipts remain retained; the client transaction rolls back safely. This is a catch-up availability/data-consistency failure, not demonstrated deletion or physical output.

**Origin and relation to the repair:** These country-reconciliation producer/consumer restrictions predate the all-remediation diff; the changed `multi_changes` function repairs ADIF insertion compatibility but leaves this supported audit kind unresolved. CR-004's particular import wire-kind and missing-identity root is repaired. FA-002's repeated-page country-hydration counterexample now passes. **Repair direction:** Introduce a wire-compatible immutable projection for historical prefix-reconcile events using complete original raw/deleted identity context plus their historical before/after country facts. New audit production should store complete identities. Preserve old audit and operation-receipt bytes; do not rewrite a past event from the current corrected identity. Test an actual open-time native-shaped primary-prefix repair on an already-baselined master/client pair, then later commit/correction/delete, replay and reopen.
