# DX alerts, nearby callsigns and Normal Logging shortcuts

DX opportunity alerts remain opt-in. Open Alerts, expand Rules, and combine bands, mode groups (CW / PHONE / DATA), novelty, DX entity/continent/CQ/ITU zone and spotter entity/continent conditions. Find DXCC entity searches the current native CTY directory by name or ADIF number; enter the selected IDs in the rule. Values within a field are alternatives; filled fields all have to match. Missing geography cannot satisfy a selected condition.

Preview retained reports evaluates the unsaved rules without creating notifications or changing the live event baseline. Existing rule configurations migrate to version 2 with unrestricted geography, retaining enabled/off state and deduplication settings. Saving or changing rules baselines existing reports without replay. A concurrent rule change preserves the attempted edits and requires Revert before a new edit.

Each retained alert records the matching reason at that time. Review spot shows that historical evidence, including unknown geography. Tune & load uses the exact native cluster observation identity, the selected radio and the existing shared-editor barrier. Test/WSJT-X/history-only entries cannot tune. When a current cluster alternative exists it must be selected explicitly; the historical report is never silently replaced. Popup delivery is passive.

Enable **Settings → Logbook → Nearby spotted callsigns** to show receiver suggestions on Operator Desk, Log QSO and the detached live QSO editor. This does not enable Follow Radio or connect a radio. The selected receiver must have fresh native frequency, mode, selection and connection-generation evidence. Split operation uses RX. Candidates are at most 10 minutes old and same-band/mode compatible; the retained cluster inventory remains the source and bounds all work to at most 500 reports. The UI displays at most three candidates, ordered by absolute offset, newest report and stable identity. Same-call repeats within 50 Hz (CW) or 250 Hz (phone) are collapsed; distinct frequencies remain choices.

Fallback half-widths are 250 Hz CW and 1,500 Hz phone. A fresh Hamlib Passband, when available from the admitted mode observation, supplies half its width with maximum half-widths of 1,000 Hz CW and 3,000 Hz phone. These are suggestion windows, not evidence that a station was identified. A 150 ms presentation coalescer consumes existing native telemetry events; no new network poller is created.

Use callsign flushes the existing draft input, revalidates the exact receiver/spot/draft coordinates, and fills an empty canonical callsign only. A typed callsign wins. RX/TX frequency, time, reports, notes, station/portable context and Follow Radio remain unchanged. Acceptance never tunes, rotates, transmits, saves a QSO or invokes spot activation. Several candidates require a visible choice.

Open **Settings → Display → Normal Logging shortcuts** for the searchable command list, key capture, effective/default bindings, per-action reset and reset-all. Save current QSO defaults to Command/Ctrl + Enter and uses the normal editor validation/save owner. Navigation, focus callsign and accepting a single nearby suggestion can receive optional bindings. The fixed native navigation accelerators remain reserved; configurable navigation bindings supplement those native menu commands. Escape/Stop, text editing, lifecycle, function/CW/contest keys are reserved. Primary + Alt is unavailable to avoid AltGr/layout collisions. Key repeat, composition and dead keys never invoke these commands; capture does not execute a command.

Bindings use a versioned revision-checked workspace document and travel through existing backup/restore. Unknown action IDs remain unavailable and are preserved. Failed or concurrent saves preserve attempted edits. Other windows reload bindings on focus. Replies are fenced by read epoch, current workspace generation and the newest accepted revision, so a late older read cannot restore superseded bindings. Native windows continue to own their existing Stop and release controls during capture.

Automated fixtures cover evaluator/migration/preview purity, exact retained identity handoff, receiver/source invalidation, callsign-only draft preservation, command conflicts/normalization and editor reconciliation. Native station/provider acceptance and cross-platform physical keyboard qualification remain separate release checks.
