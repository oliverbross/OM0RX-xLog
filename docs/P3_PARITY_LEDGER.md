### Operator-requested detachable workspaces — 2026-10-12

**Required; acceptance pending.** DX Cluster, World Map and Band Maps must each
offer an obvious **Undock** action and a **Dock back** action. Reuse existing
detached-window support where present; do not create separate applications or
duplicate cluster connections, radio sessions, logbook writers or command owners.

- Each workspace opens in a normal, independently movable and resizable window,
  including on another display; it is not forced always-on-top.
- Preserve the same live data, filters, colours, selected spot and functional
  controls between docked and detached presentations. A user action dispatches
  once, with the same authoritative observed-state completion requirements.
- Remember each window's position and size, restoring it within a visible display
  after monitor changes. Repeated Undock focuses the existing window rather than
  creating duplicates.
- Dock back and closing the detached window preserve workspace state and make
  the workspace accessible again from the main app. Neither action disconnects
  shared station/cluster services or loses the active QSO draft.
- Verify detach, move, resize, close, redock, reopen and app restart for all three
  workspaces on the packaged Mac build; retain Windows/Linux acceptance gates.

## Closure sequence and non-negotiable checks

1. **Freeze and reconcile source.** Pin final SHAs and dirty diffs for all three native baselines and the integration branch. Import each applicable native golden test/fixture once. Run a static audit confirming no required shared workflow still calls the standalone xCat or xCluster executable. Preserve external compatibility adapters only where they serve third-party applications.
2. **Finish the station authority.** One typed profile/session owner arbitrates UI, cluster and external CAT clients. Complete embedded direct FLEX/SmartLink, remote-agent policy/configuration, incoming CAT/RigCtlD, UDP spot bridge and independent managed/external Hamlib rig+rotor. Separate accepted, observed, rejected, timeout and unknown outcomes. Prioritize stop/release over logbook/sync work. Profile generation invalidates stale requests.
3. **Finish the shared operator experience.** Bring back native desk/full editor, sidebar grouping, keyboard workflow, QSO context, map controls and monitor semantics; complete cluster dense table/history/matrix/filter/rules/console and award/reference/propagation views. One selected-spot pipeline supplies every consumer.
4. **Prove data/recovery parity.** Run copied-data fixtures and restore drills before a live single-writer Wavelog acceptance. Compare counts, semantic IDs, outbox/conflicts, unknown fields, award evidence and source ages. Migration must preview and preserve each native app's settings and original data.
5. **Prove artifacts and devices.** Repeat exact final-source unit/contract/process/UI tests, then package and launch on clean OS targets. Report Mac live remote-agent, DCU-1, local Hamlib rig+rotor, SmartLink/FLEX, Maestro spot and Windows/Linux separately; name model/firmware/driver, sample trace and any operator authorization. Source tests, screenshots and prior alpha acceptance cannot substitute for those observations.

The finish line is every PAR/CAT/CLU row either accepted with linked exact-build evidence or explicitly excepted by the operator. Current status is **not complete**; the shared alpha and the uncommitted P3 work do not satisfy that finish line.
