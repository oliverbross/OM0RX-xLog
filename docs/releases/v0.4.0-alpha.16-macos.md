# Integration alpha.16 — macOS testing release

Source: `03840acb055696d7311fe7c84508350902c119ad` (version-only release commit
over tested feature source `aa40348`). This is the Integration alpha, not the
original native stable xLog app.

## Included

- Independent Spot History window in the native Window menu, with read-only
  archive search/statistics and Dock back.
- Configurable Logbook columns and widths, keyboard resizing, pinned Callsign,
  and separate docked/detached preferences.
- Compact country/DXCC context in the full QSO editor, with evidence-based
  confirmed/worked/new colours and neutral unavailable state.
- Native automatic-sync completion notifications that do not depend on the
  main renderer. Reconciliation/deletion policy is unchanged.

Feature-source verification: 839 frontend tests, 225 Rust tests, TypeScript,
production build and detached-window bundle budgets pass. Release packaging
also passes its three macOS resource checks and the rebuilt Swift worker's
fixture-only self-test. Existing large-main-bundle warnings remain.
