# Integration alpha.20 — macOS testing release

Includes the detached spot-activation, independent Monitor, bounded sync and
nine-role workspace status fixes described in [alpha.19](v0.4.0-alpha.19-macos.md).
Alpha.19 was not installed: its private acceptance passed 25 checks but still
expected the deliberately removed top-level Sync menu item.

The acceptance test now verifies visible native menu routes and the real
Settings > Sync tab, including unchanged settings and operator draft. Native
menu validation remains strict; production menus and sync permission are not
changed by this correction. Four focused actual-component tests pass. Full
frontend validation: **998/998 across 123 files**; TypeScript/Vite and detached
bundle/CSS checks pass. Unchanged native code retains alpha.19's **319/319**
test evidence.

An independently reviewed pure Follow Radio field reducer is included as a
development prerequisite. It can project only frequency, band and logging
mode, preserving all other QSO data. It is **not connected to runtime** and
does not complete independent Follow Radio or Clear after QSY. Complete
portable Swift validation: 464 passed, nine explicit skips, zero failures.

Global fully windowed mode remains disabled. Remaining Settings/Station
Control/Chaser/CW and standalone-panel migrations are tracked separately.
No isolated test proves radio/rotor hardware operation or live Wavelog
convergence. Exact source, package and installed evidence follows below.
