# OM0RX-xLog alpha.28 — workspace, window and integration hardening

Alpha.28 follows installed alpha.27 with the operator-feedback tranche: every
radio connection surface defaults to full controls; detached windows and Canvas
panels use consistent, responsive task-first layouts; Canvas/Separate Windows is
a persisted native choice; propagation freshness is repaired; anchored Wavelog
confirmations reconcile without false duplicates; and receive-only WSJT-X Logged
ADIF intake is available. The product name and original brand assets are now
OM0RX-xLog.

## Source boundary

- Exact packaged source: `ab60d7dc347d84ef8b28e02bbc00bd3c94efe0fb`.
- Remote Agent, Hamlib, Direct FLEX and local CAT-client connections start with
  transmit controls enabled. An operator can still explicitly choose receive-only
  before connecting. Real station inhibitors, hardware faults, observed-state
  requirements and durable connection fences remain authoritative.
- The shared Backups panel exposes passive native status and capability-gated
  setup verification, approval, Start, Stop, retention review and receipt-only
  recovery. Renderer input cannot provide plans, account proofs, credentials,
  package hashes or vault identities. Production provisioning and remote
  retention deletion remain unavailable.
- ADX validates signed `ALTITUDE`/`MY_ALTITUDE` and nonnegative `DISTANCE`/
  `MAX_BURSTS` decimals without changing accepted spelling, precision, order or
  ADI fallback behavior.
- A cancelled close now snapshots native-window bounds without retiring the
  still-live geometry tracker. Actual destruction or explicit flush remains the
  retirement boundary.
- Nineteen detached task windows start at their functional content and omit the
  repeated banner/navigation prose. Thirteen independent Band Map windows retain
  their own band and compact CW/Phone/Data visibility.
- Canvas panels unlock individually, move from the title and resize from all
  edges and corners. Content reflows or scrolls instead of leaving fixed blank
  regions. Lock exits editing and the exact prior Canvas preset survives a switch
  to Separate Windows and back.
- Propagation refresh has one coalesced native owner. Mount, focus and a
  60-second freshness probe share the native ten-minute cache TTL; an explicit
  click always requests a new fetch.
- Wavelog reconciliation advances remote confirmation/enrichment changes on the
  authoritative single or already-linked local contact instead of holding the
  same QSO as a false duplicate. Multiple remote IDs with differing ADIF details
  remain unchanged and visibly held rather than being guessed or merged.
- WSJT-X integration receives only official Logged ADIF message type 12 over
  loopback or IPv4 multicast. It starts only after explicit enablement, logs
  locally through semantic duplicate suppression and cannot send a UDP packet or
  any radio command.
- User-visible product naming is **OM0RX-xLog**. The existing bundle identifier
  remains unchanged so Application Support and Keychain ownership continue.
