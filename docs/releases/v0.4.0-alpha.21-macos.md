# Integration alpha.21 — macOS testing release

Includes the changes in [alpha.20](v0.4.0-alpha.20-macos.md), which was not
installed: 29 native acceptance checks passed, then Dock back from Spot History
failed after the main window was recreated.

The recreated main window correctly blocks navigation until editor registration
is ready. Previously, the navigation listener nevertheless acknowledged the
blocked route, losing the destination. A rejected navigation now remains pending
and retries when editor readiness changes; editor and dirty-input guards remain
in force. Regression tests exercise the real held-registration session.

Source, package and installed verification are separate gates. This release is
not installed until all packaged native acceptance checks pass. Global fully
windowed mode remains disabled pending the remaining panel migrations. Isolated
acceptance does not establish radio/rotor operation or live Wavelog convergence.
