# Integration alpha.22 — traditional Desk Map / Logbook and local history

Adds the reviewed traditional Desk choice: Map, Logbook, Logbook above map or
Logbook below map. The vertical divider supports pointer and keyboard resizing;
Desk Logbook columns and widths are configurable independently of the full and
detached Logbook. Panes retain their state when hidden or reordered.

Local Logbook operations retain navigation/close/activation guards. A late Import
file selection cannot bypass a newly locked editor; rejected selections clear
the picker so an explicit same-file retry works after unlocking.

The Operator Desk now reads callsign and DXCC history directly from the local
logbook. The main window previously sent that read through the live cluster
session, so statistics could appear unavailable even while the integrated
logbook was healthy. The route remains read-only and does not require a radio or
cluster connection.

Source validation before packaging: frontend **1,040/1,040** across 127 files;
Rust **320/320**; Swift XCTest 160 executed with four explicit skips plus 56/56,
and Swift Testing **240/240**; production TypeScript/Vite and detached-window
bundle checks pass.

Source evidence: [UI-39 acceptance](../DESK_MAP_LOGBOOK_SOURCE_ACCEPTANCE_2026-10-14.md).
This candidate must pass exact packaged native acceptance before replacing the
installed app. Alpha.21 remains installed until then. Global fully Windowed mode
and the remaining independent-panel migrations are not completed by this release.
The separate Settings safety worktree is not part of this package.
