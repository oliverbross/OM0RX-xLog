# OM0RX-xLog 0.3.0 — Current working macOS-only release

This is the current native macOS release for everyday use while the unified cross-platform prototype is developed separately. The existing downloadable ZIP, version tag and application are preserved unchanged. It is not a Windows or Linux application, and the prototype does not replace it.

Download **OM0RX-xLog-0.3.0-macOS.zip** below. The app is Developer ID signed, Apple-notarized and stapled. Radio/rotor control uses the existing OM0RX-xCat integration; classified cluster feeds use OM0RX-xCluster. Those companion apps remain usable during development.

The worldwide awards-library release adds a source-backed 190-programme research catalogue while retaining xLog's two additional native Chinese award calculators. It deliberately distinguishes catalogue coverage from executable qualification.

Highlights:

- A searchable 192-entry library covering global, European, worldwide and specialist programmes.
- Nine live native calculators for AJD, WAJA, JCC, JCG, AJA, WACA, WAGA, WAPC and WCSA.
- Separate worked, evidence-eligible and sponsor-credited layers for live calculations.
- Honest research-tracking, blocked and historical states for other entries, with official sources and named unresolved dependencies.
- A complete per-programme delivery ledger in `docs/AWARDS_COVERAGE.md`.
- Japanese historical-entity rules, WAPC band/mode detail and WCSA school-slot milestones calculated from the complete local log.
- Operator intelligence for awards, operating mix, propagation and local station weather.
- Compact xCluster opportunity markers and stable graphical HF-condition presentation.
- Rotor targeting and spot-to-radio handoff through OM0RX-xCat.
- A readable station sidebar with KPA500/KAT500 status, power, SWR, band, antenna and amplifier controls.
- Existing logging, Wavelog v2 synchronization, QRZ, ADIF, Operator Desk, world-map and multi-band-map features.
- Bundled MIT attribution and reference data from ham-award-tools commit `f28a04fa5a94368ac4099ce5cec97fcd93ce0849`.

“Current working release” describes this preserved macOS product; it does not certify every radio/account combination or remove the documented partial features and outstanding acceptance checks in `PROJECT_STATUS.md`. No award application, email, payment or sponsor claim is sent by the awards library.
