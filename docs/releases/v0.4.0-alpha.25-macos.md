# Integration alpha.25 — split operation, reconnect and compact Desk

Alpha.25 packages the current feature-focused tranche for operator testing. It
adds the compact Desk-split Logbook, retained map resizing, default-off Clear
after QSY, shared native Sync refresh scheduling, stricter ADX header checks and
passive verified-backup retention review evidence.

The station path now recognizes arbitrary observed RX/TX split offsets, fences
late Remote Agent socket and command replies across reconnect generations, and
does not confuse guarded KPA Operate with RF-producing CAT controls. Operate
therefore does not depend on the CAT transmit opt-in; Tune, PTT and CW remain
protected by it. Actual Agent-advertised availability, lifecycle transitions and
station inhibitors remain authoritative.

This remains an alpha. Unattended recovery after an actual Windows Agent restart
needs installed acceptance, as do the Windows Agent's exact Standby drive
rollback and structured first-retry failure handling.

## Installed station observations

Alpha.25 did not reconnect the saved Agent automatically on launch; it remained
`stopped / Radio offline`. One explicit **Connect saved Agent** recovered live
24.940000 MHz USB, RECEIVE, confirmed 12 m route, KPA Standby, KAT READY/fault 0,
output 0 W and clear alarms. This keeps unattended reconnect open.

An authorized guarded Operate check was no longer rejected by the CAT-transmit
checkbox. It reached the Agent, which rejected the operation after the observed
FLEX route changed to 24.941000 MHz during apply. KPA remained Standby and output
remained 0 W. The aborted apply left FLEX drive at 25 W instead of restoring the
12 m barefoot 90 W setup, confirming the separate Agent rollback defect. No Tune,
PTT, CW or rotor-turn command was issued.
