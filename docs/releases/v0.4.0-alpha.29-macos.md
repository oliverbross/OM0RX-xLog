# OM0RX-xLog alpha.29 — ADX coverage and final review hardening

Alpha.29 is the macOS follow-up to alpha.28. It completes the reviewed ADX
record-field coverage and closes every actionable finding from the requested
three-pass final code review without weakening radio, sync or data-safety
boundaries.

## Source boundary

- Exact packaged source: `db7ed4734826ea90cfd69b345c4d6174778894e5`.
- ADX import now validates the remaining string, subdivision, radio-enumeration,
  award-list and scalar families, including `MS_SHOWER`, while preserving ADI
  fallback and record spelling/order guarantees.
- Packaged native acceptance now performs an ADX export/import semantic round
  trip in addition to its existing renderer, worker, window and logbook checks.
- Separate-window reconciliation is independent of draft dirtiness, so a clean
  draft cannot prevent the requested native windows from opening.
- Direct transmit sessions drain acquired control leases before shutdown; FLEX
  shutdown still attempts PTT off if tune-off fails; CAT whitespace-only `KY`
  remains a real CW-clear command; and Remote Agent frequency confirmation is
  fenced to the exact connection identity and generation.
- Wavelog destination changes are blocked while linked contacts exist. Import
  lookup uses effective submode semantics, reference data is preflighted before
  database replacement, reviewed remote baselines advance atomically, conflicts
  cannot starve later pending uploads, and acknowledged mutation receipts are
  pruned from the bounded journal.
- The macOS CI package contract uses the current app and artifact names.

The requested review produced twelve actionable findings across UI/runtime,
station-control safety and data/synchronization correctness. All twelve were
fixed and covered by regression tests before packaging.
