# Integration alpha.19 — macOS testing release

## Included since the installed alpha.16

- Native detached spot activation for World Map, Band Maps and Cluster, with
  shared-editor admission, durable operation receipts and no blind replay.
- Independent Monitor observations and compact Auto Rotor Arm/Off controls.
  Delayed Arm cannot override later Off or Stop; stale permissions fail closed.
- Bounded Wavelog reconciliation steps so foreground database work can run
  between background steps. Live convergence and end-to-end latency remain
  separate acceptance items.
- Correct recognition of all nine implemented native window roles in Settings.
  A six-role frontend validator had rejected native status and hidden placement
  selectors; the native package acceptance exposed this production defect.
- Corrected native acceptance editor-focus check, without duplicating the
  native shortcut in the renderer or weakening draft protection.

The traditional Desk remains available. Global all-independent-window mode is
not complete or enabled. Settings, Station Control, Chaser & DX, shared Follow
Radio intent and remaining standalone panels still need work.

## Validation and delivery

The window-role regression was reproduced before the fix. Its 72 focused
tests, TypeScript checks and independent review pass. Complete frontend suite:
**994/994 across 122 files**. Native Rust: **319/319**. Production Vite and
detached-window bundle/CSS gates pass. The unchanged portable Swift layer
retains alpha.17's 457-passed/9-explicit-skips evidence, not a new run.
Exact package results will be recorded below after completion.

Alpha.17 failed an obsolete shortcut acceptance step. Alpha.18 passed that
step but exposed the real native-window status mismatch. Neither failed
candidate was installed. Reports remain under `dist/` for evidence.

No RF, radio tuning, rotor motion or station hardware acceptance is implied by
isolated local-workspace tests. Those tests cannot access external services or
the operator's real logbook. The original native app is not being replaced.
