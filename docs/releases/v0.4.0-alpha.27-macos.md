# Integration alpha.27 — rotor resume, Sync mode fencing and DATA-10

Alpha.27 is a focused follow-up to installed alpha.26. It resumes a saved DCU-1
rotor connection at native startup, binds automatic Wavelog Sync consent to the
SQLite-owned mode/destination epoch, and extends standards-aware ADX validation.

## Source boundary

- Exact packaged source: `038ab3f2ead72de3c719e890a6ede79ed251e4ef`.
- Rotor startup supports saved DCU-1 configuration only. It issues one connection
  request and has no Turn, Stop or other motion path. Explicit disconnect,
  pending/unknown outcome, changed configuration/workspace and stale ownership
  suppress resume.
- Standalone local mode rejects QSO Sync before credentials or transport while
  preserving contacts, conflicts and outbox. Returning to Wavelog mode never
  restores old automatic consent; the operator must explicitly re-enable it.
- ADX validation now includes exact location/VUCC lexical rules and the reviewed
  exchange/completion status enums. Accepted text remains exact; invalid ADX
  fails closed and ADI behavior is unchanged.
