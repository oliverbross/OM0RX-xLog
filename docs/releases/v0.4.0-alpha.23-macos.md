# Integration alpha.23 — independent windows, ADX metadata and guarded backups

Alpha.23 packages the current dependency-ordered feature tranche. It adds the
independent guarded CW window, passive Rotor, Station Status and Propagation
windows, shared Settings/Station ownership work, lossless versioned ADX
extension metadata with exact USERDEF ranges, UUID-bound backup execution and
the exclusive independently verified Dropbox transport foundation.

The release keeps unfinished authority hidden. Passive windows do not start new
hardware polling, and Dropbox has no OAuth/account UI or scheduled consent path
yet. The global Windowed preset remains disabled. Exact Direct FLEX receive
frequency is source-complete, while exact mode and hardware-profile apply remain
blocked on explicit-slice and conditional-write backend contracts.
