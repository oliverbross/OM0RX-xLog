# 1.5.16 isolated desktop quality candidate

This version advances the user-visible candidate identity for the quality fixes.
It is not installed or published. The daily Mac remains the retained 1.5.15;
the verified 1.5.9 rollback remains available.

The source pin is the full clean commit passed to
`bash docs/releases/build-1.5.16-macos-arm64.sh <exact-source-sha>`.
Before compilation the no-clobber recipe writes that exact SHA/version/platform
to `.build/releases/1.5.16/build-input.txt`. It verifies the same identity in the
ZIP-extracted signed `NativeBundleBuild.json`, verifies signatures and arm64
host/worker slices, runs the existing nine signed-worker checks without deadline
changes, and records final executable/archive hashes. The master
[quality tracker](../audits/quality-2026-11-05/README.md) records the resulting
source SHA and artifacts once produced; an unbuilt candidate has no implied
artifact or passing packaged acceptance.

Windows/Linux use the same committed version/source via the canonical
Cross-platform beta qualification workflow, dispatched with
`build_platforms=all`, `validation_only=false`, `package_macos=false`.
Windows produces separately named current-user and all-users installers from
one audited payload, with scope/source/hash receipts. Runtime acceptance uses
fresh hosted runners per installer scope. Hosted elevation is explicitly not
standard-user/UAC evidence. These are internal qualification artifacts, not a
GitHub Release.

Included fixes: first-run rotor envelope/retry, completed worker task lifetime,
hidden/suspended CW polling with preserved refresh deadlines, bounded POTA chunk
conversion, and Windows installer scope/default-path validation. Functional
commits and before/after evidence are linked from the master tracker.

The original radio incident, complete htop ~7 GB incident attribution, whole-app
idle/operation budgets, actual ordinary-user Windows installation and native
equipment journeys, upgrade/rollback/media retention, broader platform parity,
physical devices and notarization remain open until specific evidence closes
them. No claim of all-platform equivalence or complete memory resolution is
made by preparing this candidate.
