# OM0RX-xLog 1.2.23 — responsive propagation, RBN pickups and country corrections

Version 1.2.23 keeps the Operator Desk compact when only a few previous QSOs
exist, keeps both ends of a selected map route clear of its controls, and
improves HF Propagation Live for different window sizes. Radio, rotor,
amplifier and online-log behavior are unchanged by these changes.

## Source boundary

- Exact packaged source: `a2b959da84796babf6b3158a34071e121203ba28`.
- Source branch: `codex/dual-radio-settings`.
- `Worked before` columns are independently resizable. The panel grows only to
  its data, without horizontal or vertical scrollbars, and the logbook receives
  the remaining space while the map retains the lower half.
- Automatic route framing accounts for the map toolbar, legend and callsign
  labels, while preserving operator-controlled map movement.
- HF Propagation Live adds a Layout control beside Settings, responsive
  one/two/three-column presentation, balanced WSPR and band-activity panels,
  and a full-width Modes per band section.
- Heavy propagation analysis refreshes on a slower cadence and cached content
  hydrates after the first render to improve perceived startup performance.
- `OM0RX RBN pickups` shows who heard the station in the Reverse Beacon Network,
  including skimmer, UTC, band, frequency, mode, SNR, speed, country and grid.
- The RBN client handles the network's challenge/response handshake and bounds
  response sizes before parsing.
- PJ4 calls such as PJ4Y resolve to Bonaire (DXCC 520), while Bangladesh remains
  correctly associated with its ordinary S2/S3 prefixes.
- Compact cluster country labels display `Germany` and `USA`; the underlying
  DXCC identity remains unchanged.
- HF Propagation Live now has a full `Arrange panels` mode: drag any panel title
  to move it, resize from every edge or corner, choose information density, or
  reset the persisted layout. Narrow windows retain the responsive stacked
  presentation.
- SFI, sunspot number, A, Kp, X-ray and solar-wind values use distinct,
  high-contrast colors so the live indices can be separated at a glance.
- The full desktop sidebar adds a compact, passive `RBN / Spotted` area under
  Station. It shows up to four recent own-call RBN/skimmer or human spots and
  automatically reduces or hides the cards when vertical or horizontal space
  is constrained.
- HF Propagation Live and the sidebar share a deduplicated own-call RBN request.
  The sidebar polls the native RBN transport even when the cluster is
  disconnected, then merges those pickups with recent human spots.
- Both the full DX Cluster page and the compact Operator Desk cluster render an
  `RBN` badge for the native backend's `rbl` source identity.
- DXSpider FT decoder reports that omit the traditional `-#` skimmer suffix are
  now classified as RBN when their mode, SNR and audio-offset signature is
  present. Ordinary human FT8 and CW comments remain DX Cluster spots.

## Installed-app acceptance

The relaunched installed application restored the existing integrated logbook
with 68,200 contacts. It showed the Remote Station Agent radio as `Connected`
at 3.733700 MHz LSB, the rotor connected and stopped at an observed 84 degrees,
KPA500 in `OPERATE` with 0 W output and live SWR 1.21, and ShackCQ connected
with a changing live feed of 26–34 current spots. Live cluster rows displayed
the compact `Germany` and `USA` country labels.

HF Propagation Live visibly exposed the `Arrange panels` control beside Settings, the
responsive dashboard, the full-width Modes per band section and the new
`OM0RX RBN pickups` panel. At acceptance time the panel correctly reported that
no RBN skimmer had heard OM0RX in the last ten minutes; the RBN source summary
was live. PJ4Y was not present in the current cluster feed, so its Bonaire
correction is established by the focused native resolver regression rather than
by clicking a live spot.

The installed dashboard also visibly exposed `Arrange panels`, move handles,
all eight resize directions, the information-size selector and layout reset.
The six solar indices rendered with distinct cyan, green, amber, coral, pink
and violet values. The full desktop sidebar showed `RBN / Spotted · OM0RX`
under the Station telemetry. No own-call pickup existed in the ten-minute live
window, so the verified installed empty state read `No pickups in the last 10
min.` The compact cluster source modal temporarily accepted `RBN / Skimmer`
and FT8 without changing station hardware. The durable archive contained eight
recent RBL observations carrying `source: rbl` and the `RBN source` reason,
but no fresh RBN report arrived after restart during the acceptance window, so
this receipt does not claim a newly observed installed-app badge. The full and
compact badge behavior is established by the focused 39/39 renderer tests.
The user's original DX Cluster-only and CW/SSB filter selection was restored
before handoff.

This acceptance intentionally did not click a live cluster spot, command
physical rotor motion, switch the amplifier, transmit, log a QSO, or run a live
Wavelog synchronization. Those actions require operator observation of the
remote station and are not inferred from local UI state.
