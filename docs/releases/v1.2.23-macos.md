# OM0RX-xLog 1.2.23 — responsive propagation, RBN pickups and country corrections

Version 1.2.23 keeps the Operator Desk compact when only a few previous QSOs
exist, keeps both ends of a selected map route clear of its controls, and
improves HF Propagation Live for different window sizes. Radio, rotor,
amplifier and online-log behavior are unchanged by these changes.

## Source boundary

- Exact packaged source: `ea382fd14cada07160d99bb26411f54c43fe2e25`.
- Source branch: `codex/dual-radio-settings`.
- `Worked before` columns are independently resizable. The panel grows only to
  its data, without horizontal or vertical scrollbars, and the logbook receives
  the remaining space while the map retains the lower half.
- Automatic route framing accounts for the map toolbar, legend and callsign
  labels, while preserving operator-controlled map movement.
- HF Propagation Live adds a Layout control beside Settings, responsive
  one/two/three-column presentation, balanced WSPR and band-activity panels,
  and a full-width Modes per band section.
- Heavy propagation analysis refreshes on a slower cadence and cached content
  hydrates after the first render to improve perceived startup performance.
- `OM0RX RBN pickups` shows who heard the station in the Reverse Beacon Network,
  including skimmer, UTC, band, frequency, mode, SNR, speed, country and grid.
- The RBN client handles the network's challenge/response handshake and bounds
  response sizes before parsing.
- PJ4 calls such as PJ4Y resolve to Bonaire (DXCC 520), while Bangladesh remains
  correctly associated with its ordinary S2/S3 prefixes.
- Compact cluster country labels display `Germany` and `USA`; the underlying
  DXCC identity remains unchanged.

## Installed-app acceptance

The relaunched installed application restored the existing integrated logbook
with 68,198 contacts. It showed the Remote Station Agent radio as `Connected`
at 1.825800 MHz CW, the rotor as `ROTOR CONNECTED`, KPA500 in `STANDBY`, and
ShackCQ connected with 59 current spots. Live cluster rows displayed `Germany`
and `USA` instead of the longer source names.

HF Propagation Live visibly exposed the Layout control beside Settings, the
responsive dashboard, the full-width Modes per band section and the new
`OM0RX RBN pickups` panel. At acceptance time the panel correctly reported that
no RBN skimmer had heard OM0RX in the last ten minutes; the RBN source summary
was live. PJ4Y was not present in the current cluster feed, so its Bonaire
correction is established by the focused native resolver regression rather than
by clicking a live spot.

This acceptance intentionally did not click a live cluster spot, command
physical rotor motion, switch the amplifier, transmit, log a QSO, or run a live
Wavelog synchronization. Those actions require operator observation of the
remote station and are not inferred from local UI state.
