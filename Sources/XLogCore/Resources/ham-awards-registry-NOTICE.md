# Worldwide awards research registry notice

The bundled `ham-award-research-registry.json` is a dated implementation input supplied to the OM0RX-xLog project and reviewed on 2026-10-11 UTC (2026-10-12 Australia/Darwin).

It contains 190 curated programme/family records, 22 shared sponsor profiles, official source links, concise research summaries and unresolved questions. It does not reproduce complete sponsor rulebooks, reference directories, membership histories, application forms or credentials. Each record retains its source and review date so executable rule packs can be audited against current primary material.

Registry presence does not imply that a programme is currently accepting applications, that xLog has implemented its complete rules, or that an operator qualifies. xLog exposes an explicit delivery state for every record. Only audited native rule packs can produce local progress; all other records fail closed as research tracking, blocked, or historical/discovery.

Programme names and sponsor names identify their respective organisations and award systems. Refer to each record's official source links for current rules, permissions, fees, manager details and application routes.
