# CW macros — Settings and Operator Desk

Operate mode; a narrow code-led extension of the established xLog console.
The operator requested up to 20 configurable, coloured macros, keyboard shortcuts,
optional desk buttons and supported-radio or independent WinKeyer output.
Unattended implementation was explicitly requested; no new visual identity or
transmission test is authorized.

## Direction contract

THESIS: Prepare CW once, then operate from a compact, explicitly armed row. Editing
and preview never send, and uncertain output always retains its Stop obligation.

OWN-WORLD: Inherit navy working surfaces, system typography, compact labelled
fields and existing control shapes. Named macro colours tint labels/borders;
colour never substitutes for a name or state.

STORY: Select an output, edit one of 20 macros, preview substitutions and Save.
Connect separately, arm for a limited period and send deliberately. A connection,
focus or profile change disarms without replaying text.

FIRST VIEWPORT: Settings has output/profile controls above a compact macro list
and one selected editor. Desk buttons occupy one row under Active QSO; overflow
uses a labelled More menu rather than a horizontal scrollbar. Arm and Stop remain
visible and distinct from coloured macro buttons.

FORM: Extend the incumbent directly; no concept seed applies. The signature
interaction is a live non-transmitting preview paired with explicit safe output.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
