# Native workspace navigation

Mode: Operate. Extend the existing desktop shell, preserving its visual system and all logging/station safety boundaries. User explicitly requests familiar native menus and eventual optional all-screen undocking; work is unattended.

## Direction contract

THESIS: Every existing workspace destination is reachable through ordinary native menus; navigation is never a radio or synchronization action.

OWN-WORLD: Inherit OS-native menu typography, focus and disabled states, plus the existing navy/cyan/teal content surfaces. No decorative menu icons or new title rows.

STORY: The operator opens Logbook, Station or View, chooses a named screen, and the existing desk is focused without disturbing a draft or connection.

FIRST VIEWPORT: Platform app/Edit/Window/Help menus stay intact. Logbook groups entry, history, awards and sync; Station groups controls/settings; View groups cluster/maps/chaser plus existing size presets. Existing detached windows are discoverable under Window. The sidebar remains during migration until complete native routing/window recovery is accepted.

FORM: Precisely requested native-menu extension; no seed or concept tournament applies. Signature interaction is immediate, non-mutating navigation with a retained native request until the main view acknowledges it. No authored decorative motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Acceptance: complete route inventory, invalid-label/unknown-route rejection, delivery before listener startup and stale-response handling, no RF/sync side effects, native keyboard/menu inspection on the exact packaged build. No new raster assets. Native review remains pending until that build is available; source tests do not close it.
