# Independent map viewing

Mode: Operate. Precisely scoped ownership extraction; inherit the existing World Map and Band Maps composition and navy console. No redesign, seed, artwork or system-token change.

THESIS: Retained live map context and durable Band Maps preferences remain available without a main renderer.

OWN-WORLD: Existing Map/BandMaps components, compact system controls, semantic call/frequency/status colours and existing accessible chart labels.

STORY: Open either native window, inspect current reports, adjust saved Band Maps view preferences, refresh service state, and dock back. Inspection cannot activate a QSO, tune a radio or turn a rotor.

FIRST VIEWPORT: Preserve the existing map/chart as the primary content, with compact Refresh/Dock actions and an explicit inspection-only notice. Retained/stale/service-error states remain readable without hiding the content.

FORM: Native cluster/radio owners remain the only live owners. Wake events trigger scoped retained reads; the renderer never owns a station connection. Band Maps edits require generation-bound field-patch acknowledgements. Existing embedded activation remains unchanged.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Acceptance is deliberately partial operational parity: detached activation awaits an authenticated native controller with canonical draft/editor fences. Source/unit/rendered and packaged main-absent acceptance remain separate. Existing renderer DX Cluster event spoofability is an open pre-existing authority gap, not claimed isolated by the new map IPC gate. DESIGN.md remains authoritative; no new raster assets.

Per-report classifications retain the existing native cluster feed's eventual consistency after logbook changes/restore; they are not an atomic join with the current workspace metadata. Source freshness is bounded separately from aggregate read freshness. No detached activation consumes those classifications as authority.
