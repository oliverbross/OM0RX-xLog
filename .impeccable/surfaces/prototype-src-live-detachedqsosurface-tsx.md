# Detached Log QSO

Mode: Operate. Precisely requested extension of the existing full QSO editor,
not a new visual identity. Keep the docked editor and shared canonical draft.

## Direction contract

THESIS: Log a new contact in its own native window without a second logbook or
dependence on the main renderer.

OWN-WORLD: Existing navy operator-console surfaces, compact system type, cyan
context, green primary Save and familiar labelled fields. Reuse QSOEditor;
no new artwork, animation or design-system changes.

STORY: Open Log QSO from Window or its native shortcut, edit the shared draft,
save locally, and resolve conflicts without losing local text.

FIRST VIEWPORT: Native title identifies Log QSO. A compact toolbar provides Dock
back, followed by existing inline recovery notices and the full editor. Keep
Save/Clear in their existing location and responsive field layout.

FORM: Precisely specified extension; no seed. One canonical backend, independent
recovery journal and revision-checked writes. Acknowledged draft text can close;
dirty, uncertain or conflicted work cannot silently disappear. Radio controls
remain unavailable until their independent native capability exists.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Acceptance: shared-draft conflicts and receipts, separate recovery journal,
close/dock protection, focused-window native shortcuts, main-window recovery,
scoped IPC and compact/desktop synthetic captures. Real packaged native
main-absent logging remains a separate gate; no live log or station writes.
