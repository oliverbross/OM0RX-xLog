# OM0RX-xLog 0.1.0

The first public preview of the native, local-first OM0RX macOS logbook.

Highlights:

- Wavelog API v2 two-way synchronization with visible conflict review.
- Fast SQLite logging, editing, search, confirmed deletion and undo.
- Wavelog-style QSO, Station, General, Notes and QSL fields.
- QRZ enrichment, Club Log CTY, LoTW activity and Wavelog catalog updates.
- ADIF import/export with preservation of unknown application fields.
- Live OM0RX-xCat frequency/mode and OM0RX-xCluster spot handoff.
- Previous-QSO history, band/mode matrix and compact station insights.
- A unified Operator Desk with compact logging, station state, hybrid world map and selected band maps visible together.
- Independently resizable World Map and Band Maps windows for multi-display operating positions.
- Live xCluster colour fidelity, a worked/confirmed DXCC overlay, and an accurate great-circle path with distance plus short-/long-path bearings.
- Full-band and CW/data/phone band-map presets, pan/zoom controls, allocation shading and collision-aware spot labels.
- Structured POTA, SOTA, IOTA, WWFF and castle references promoted from cluster spots into ADIF fields.
- Independent Operator Desk and undocked band-map selections: the desk can follow the live radio while a second screen keeps any other bands open.
- Full-height single-row or adaptive-grid band-map layouts with persistent 80–200% text scaling.
- Band-map and world-map spots follow the filters already applied in OM0RX-xCluster.
- Read-first, complete-history Wavelog synchronization with stable-snapshot validation before deletions, safe preservation of local-only ADIF data, and support for either a site URL or full API-v2 URL.
- Full Wavelog ADIF enrichment paired with stable JSON IDs, preserving correct DXCC and worked/confirmed colours throughout xLog and xCluster.
- Callsign changes clear stale automatic identity fields, and the map automatically fits the home station, DX station and complete path.
- Configured Wavelog installations now reconcile immediately at launch instead of temporarily appearing unconfigured until the first timer interval.

The downloadable app is Developer ID signed but not notarized. Live QRZ and Club Log paths require the operator's own credentials; Wavelog bootstrap has been exercised against the owner's production station profile for this release.
